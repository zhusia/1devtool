# 1DevTool

One workspace. Every AI agent. Every project.

Open-source Electron desktop app for orchestrating AI coding agents (Claude Code,
Codex, Gemini, Cursor, aider, and more) — terminals, projects, orchestration
dashboards, data tools, and remote access, all in one place.

## Open-source build

This is the **fully unlocked** open-source build. The previous commercial
licensing (LemonSqueezy) and entitlement gate are removed:

- No license key is required.
- All Pro features are available to everyone.
- No calls to `store.stoicsoft.com` or `api.lemonsqueezy.com`.

The code in this repository is a build of the desktop app source
(compiled output). It is published for reference and self-hosting.

## Running

```bash
npm install
npm start
```

Requires Node.js >= 20 and Electron.

## Features

- AI agent workspace: drive Claude Code, Codex, Gemini CLI, Cursor, aider and
  more from one place
- Built-in terminals (xterm.js + node-pty) with tmux support
- Project management, orchestration dashboard and agent teams
- Database tools (Postgres, MySQL, MongoDB, Redis, ClickHouse, Kafka and more)
- HTTP client, Git worktrees, LSP support, remote access & tunnels
- MCP server support
